# map 26-27

## Layout
- `code/`: all project code
- `vault/`: the Obsidian vault for this project (open this folder in Obsidian)
  - `Overview.md`: what the project is, goals, to-dos
  - `Log.md`: running list of what got done, newest at the top

## How Claude should work here
- Before starting work, read the notes in `vault/` for context.
- After building or changing something, add a dated entry to the top of `vault/Log.md` that says what was done, which files changed, and anything left to do.
- If a topic needs more detail (for example, how a feature works), create a new note in `vault/` and link it from `Log.md` with `[[Note Name]]`.
- Update the to-do list in `Overview.md` when things get done or new tasks come up.
- Keep notes short and simple. I'm still learning.
- Never touch the `vault/.obsidian/` folder.
