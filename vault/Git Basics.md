# Git Basics

This folder is connected to GitHub: github.com/snowkang08-star/map26-27

## Saving your work (3 commands)
Run these in the VS Code terminal (Terminal → New Terminal):

```
git add .
git commit -m "what you did"
git push
```

- **add**: pick the changed files to save
- **commit**: make a save point with a short message
- **push**: upload save points to GitHub

## Words
- **Repo**: a project folder that git tracks
- **Commit**: a save point
- **Push / pull**: upload to / download from GitHub
- **.gitignore**: list of files git skips (we skip `vault/.obsidian/`)

## Tip
Put an issue number in a commit message, like `closes #17`, and GitHub closes that issue when the commit is pushed.
